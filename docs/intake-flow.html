2 · Agent duplex on a mature substrate — reads fan out, writes funnel

The asymmetry is the design: reads are direct, addressed, and cacheable; there is exactly one write door, and nothing an agent emits becomes graph until it survives the audit. Context is a cache over the substrate — key · resolution · freshness.

agent context = cache over substrate never the source of truth
  • R1 resolve name → lineage head canonical? superseded? retracted?
  • R2 read quantum at CID, at the resolution you'll assert
  • R3 verify witness recompute — dual route, no trust required
  • R4 corroborate assertion count / locked fraction on a proposition
  • R5 probe dedup gate before computing skip the call
  • R6 heartbeat consensus_root vs released root drift → halt
  • W1 claim anything the agent wants the graph to hold
  • W2 computed result + generator quantum provenance = replayable program
  • W3 review resolution superseding structuring quantum
  • W4 retraction / supersession new attestation, never an edit

cross-audit → dedup gate → promote / queue an agent's write is a submission of an attributed, falsifiable act — the substrate, not the agent, decides what becomes graph. A wrong write is a quantum with an author, not corruption.

Failure modes, by construction: hallucinated claim → disagrees with other routes → queued, never silently graph · re-derived dead end → blocked at the door by the negative ledger · stale context → witness verify / heartbeat catches it on read · formatting churn → urtext absorbs it before addressing.
